# Base de datos

- `changes/` — un archivo por cambio de base (`AAAAMMDD_descripcion.sql`).
  Es el registro histórico y la forma de pasar mejoras entre marcas.
- `plantilla.sql` — **pendiente**: estructura completa (tablas, tipos, funciones,
  RLS, triggers, buckets) sin datos de negocio, para crear el Supabase de cada
  marca. Ver `docs/bitacora.md`.
